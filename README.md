# Auto-farm-Minecraft-bot
Бот сам обслуживает пшеничную ферму в Minecraft: сеет, ускоряет рост костной мукой, жнёт зрелое и пересаживает. Урожай копит и отдаёт игроку пачками по 16. Лишние семена кидает в компостер, оттуда забирает муку. Если дроп недостижим — скипает. При обрыве связи переподключается сам.
