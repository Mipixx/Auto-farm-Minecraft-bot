# Mineflayer Wheat Farmer (Minecraft 26.1)

Автоматический фермер на [Mineflayer](https://github.com/PrismarineJS/mineflayer) для Minecraft **Java 26.1**.

Бот обслуживает пшеничную ферму на локальном мире / Open to LAN: сеет, ускоряет рост костной мукой, жнёт урожай и отдаёт пшеницу игроку пачками по 16. Лишние семена кидает в компостер, готовую костную муку забирает сам.

## Что умеет

- Засевает все свободные грядки (`farmland`) в радиусе
- Ускоряет рост пшеницы **костной мукой**
- Жнёт зрелую пшеницу (age 7) и сразу пересаживает
- Копит урожай и **кидает ближайшему игроку только по 16 шт.**
- Не подбирает обратно пшеницу, которую только что отдал игроку
- Кидает лишние семена в **компостер**, забирает муку с полной компостицы
- Бежит за **костной мукой** с пола
- Не зависает на недостижимом дропе — скипает и продолжает работу
- Автопереподключение при дисконнекте

## Требования

- Node.js **≥ 22**
- Minecraft **26.1** (offline / Open to LAN)
- Рядом с ботом: грядки, семена, компостер, костная мука (на старте)

## Запуск

```bash
cd ~/mineflayer-bot
./start.sh
```

По умолчанию: `127.0.0.1:25565`, ник `Farmer`, auth `offline`, версия `26.1`.

Переменные окружения:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `MC_HOST` | `localhost` | Хост сервера |
| `MC_PORT` | `25565` | Порт (для LAN смотри порт в чате «Open to LAN») |
| `MC_USERNAME` | `Farmer` | Ник бота |
| `MC_AUTH` | `offline` | `offline` или `microsoft` |
| `MC_VERSION` | `26.1` | Версия протокола |
| `FARM_RANGE` | `48` | Радиус работы |
| `SEED_RESERVE` | `16` | Сколько семян оставлять на посадку |

Пример:

```bash
MC_HOST=127.0.0.1 MC_PORT=25565 ./start.sh
```

## Чат-команды

- `stop farm` — остановить цикл
- `start farm` — снова запустить

## Стек

- `mineflayer` (GitHub master — поддержка 26.1)
- `mineflayer-pathfinder` — навигация к грядкам / дропу / игроку

## Цикл работы

1. Подобрать костную муку с пола  
2. Забрать муку из полной компостицы  
3. Подобрать семена / пшеницу с фермы  
4. Засеять пустые пашни  
5. Скомпостировать лишние семена  
6. Ускорить рост костной мукой  
7. Сжать зрелую пшеницу и пересадить  
8. Отдать игроку пачку из 16 пшеницы (если игрок виден)

Если игрока рядом нет — бот просто копит пшеницу в инвентаре и продолжает ферму.
